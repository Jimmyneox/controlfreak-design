# App icons / favicons

Per PARENT_BRAND.md v1.4: corporate = PCB circuit wordmark; the **navy teardrop is retired** (including as a favicon).
The full PCB wordmark does not read at 16–32 px, so favicons use the **PCB simplified icon**.

## PCB simplified icon masters — `_masters/`

`control-freak-pcb-icon-{navy,white,cream,forest,gold,cool-blue}.svg`, generated by `make_masters.py` from
`brand/corporate/control-freak-corporate-wordmark-navy.svg`. It is a small-size simplification of the existing
corporate art, **not a new logo**: the corporate "C" glyph, the two bus bars, and terminal nodes, with traces/nodes
thickened for 16–48 px. Do not use it in place of the wordmark at normal sizes.

| `pool/` | `brand/masters/control-freak-mark-icon.svg` | forest on cream (legacy, unchanged) | controlfreakpool.com |

Each set: `favicon.svg`, `favicon.ico` (16/32/48), `favicon-{16,32,48}x{…}.png`, `apple-touch-icon.png` (180),
`icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `mstile-150x150.png`, `site.webmanifest`, `head-snippet.html`
(root-relative paths — adjust prefix if a product site is not served at its own root).

Preview: `_preview-favicon-sets.png` (32/48 at 1:1 and 2×, light + dark chrome).

## Rebuild (cairosvg + Pillow), from repo root

    python3 brand/app-icons/make_masters.py      # PCB icon masters
    python3 brand/app-icons/build_icons.py       # all sets except pool (+ preview)
    python3 brand/app-icons/build_icons.py pool  # also rebuild pool
