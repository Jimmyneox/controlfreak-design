# Public-repo rules

This repository is **public**. Keep it clean:

1. **No App Store app internals** — anything that belongs only to the current App Store app (private APIs, unpublished store listing copy, internal builds, keys, review notes) stays out of this repo.
2. **No private Platform product specs** — Wave 1 briefs, DECISIONS, board pinouts, and other `controlfreak-platform` private content stay in that private repo. Nest product work under `brand/PARENT_BRAND.md` rules without pasting private docs here.
3. **OK here** — parent brand masters, lockup packs, favicons, controlfreakpool.com marketing site source, public press/kit assets, and co-brand guidelines already published in `PARENT_BRAND.md`.

When in doubt, ask James or Chief before committing.
